1️⃣ Project Overview

Road Safety GIS is a native Android application designed to promote road safety through community-driven hazard reporting and real-time map visualization. Users can report accidents, potholes, construction zones, and traffic congestion—all pinned to GPS coordinates and displayed on a live Google Map.

💡 Why this project matters In India alone, over 1.5 lakh road accidents happen annually. This app empowers citizens to share real-time road conditions, helping save lives through awareness and preparedness.

Key Highlights

  • Real-time hazard mapping with color-coded zones (red=accident, orange=pothole, amber=construction, blue=traffic)
  • Emergency features — SOS with Morse code vibration, one-tap emergency call to 112
  • Speed monitoring on the map with overspeed color warnings
  • Shake-to-Report — just shake your phone on the map to quickly report a hazard
  • Nearby services — find police, hospitals, and gas stations instantly
  • Dark mode support for nighttime driving
  • Offline capable — all reports stored in local SQLite database

6️⃣ Activities (Screens) — Detailed Explanation

📱 MainActivity.java MODIFIED
com.example.saferoutegis.MainActivity

Purpose: App's splash/launcher screen. First thing users see.

What it does:

  • Shows a gradient background with decorative circles and glowing logo
  • Animates the logo with a bounce effect using OvershootInterpolator
  • Staggered animations: Logo (0ms) → Glow (200ms) → Name (400ms) → Tagline (700ms) → Features (1000ms)
  • Creates the notification channel at startup via NotificationHelper.createNotificationChannel()
  • After 2.8 seconds, checks SessionManager.isLoggedIn() and routes accordingly

Key Methods:

  • buildBounceIn() — Creates a scale animation with overshoot for the logo
  • buildFadeScaleIn() — Standard fade + scale animation for text elements
  • navigateNext() — Routes to Dashboard or Login based on session
🏠 DashboardActivity.java MODIFIED
com.example.saferoutegis.activities.DashboardActivity

Purpose: Main home screen after login. The app's central hub.

Sections in the layout:

  • 📊 Header — Gradient with personalized "Hello, {name}!" + active alert count badge
  • 🃏 Feature Cards — 7 cards: Live Map, Traffic, Safe Routes, Accidents, Potholes, Construction, Directions
  • 🆘 Emergency — Emergency Call 112 + SOS Alert (side-by-side red cards)
  • 📍 Share Location — Green card that shares GPS via any app
  • 🏥 Nearby Services — Police 🚔, Hospital 🏥, Fuel ⛽ cards
  • 💡 Safety Tips — Green info card with safety advice
  • 📱 Bottom Nav — Home, Map, Report, Alerts, Profile

Key Methods:

  • dialEmergency() — Shows confirmation dialog, then opens dialer with ACTION_DIAL
  • triggerSOS() — Vibrates with Morse SOS pattern → shows emergency dialog
  • shareCurrentLocation() — Gets GPS, creates Google Maps link, opens share intent
  • searchNearby(query) — Opens Google Maps app with "police station near me" etc.
  • vibratePhone() — Creates Morse SOS vibration: {0, 100, 100, 100, 100, 100, 200, 300, ...}
🗺️ MapActivity.java MODIFIED
com.example.saferoutegis.activities.MapActivity

Purpose: Live Google Map with hazard visualization and safety tools.

Implements: OnMapReadyCallback, SensorEventListener

🏎️ Speed Monitor Uses LocationCallback with 2-second intervals. Converts location.getSpeed() from m/s to km/h. Changes color: normal (black) → orange (>60 km/h) → red (>80 km/h).
📳 Shake to Report Registers accelerometer sensor. Calculates acceleration magnitude minus gravity. If > 12.0 threshold and last shake was > 2 seconds ago → vibrates + opens ReportIssueActivity.

Colored Circle Overlays:

  • Each hazard marker has a semi-transparent colored circle around it
  • fillColor = 20% opacity of the base type color
  • strokeColor = 60% opacity with 2px width
  • Radius scales with severity: Low=150m, Medium=200m, High=300m

Key Methods:

  • loadReportMarkers() — Draws markers + circles on background thread, then UI thread
  • updateSpeed(Location) — Calculates speed, updates TV, changes color
  • onSensorChanged(SensorEvent) — Shake detection core logic
  • shareCurrentLocation() — Creates shareable Google Maps link
  • checkNearbyHazards(Location) — Queries DB for nearby reports, sends notification
🚨 AlertsActivity.java MODIFIED
com.example.saferoutegis.activities.AlertsActivity

Purpose: Displays all road hazard reports in a filterable RecyclerView.

Filter Chips: Uses Material ChipGroup with Chip.Choice style. Chips use ColorStateList for proper white-on-blue text visibility.

🔐 LoginActivity.java / RegisterActivity.java
Authentication screens

Standard email/password login and registration forms. Passwords hashed via PasswordUtils. On success, creates a session via SessionManager.createLoginSession().

📝 ReportIssueActivity.java

Form with issue type spinner, title, description, severity radio buttons, GPS location auto-detect, optional photo upload. Saves to SQLite and shows a notification.

1️⃣4️⃣ Setup & Configuration

Step 1: Clone & Open

git clone <repository-url>
# Open in Android Studio → File → Open → Select project folder

Step 2: API Key

Edit app/src/main/res/values/strings.xml and replace:

<string name="google_maps_key">YOUR_API_KEY_HERE</string>

Step 3: Enable Google APIs

  1. Go to Google Cloud Console
  2. Enable Maps SDK for Android
  3. Enable Directions API
  4. Enable Geolocation API (optional)

Step 4: Build & Run

Click Run ▶️ in Android Studio. Use a physical device for GPS and shake features.

⚠️ Important Speed monitor and shake-to-report features require a physical device. Emulators simulate GPS but not accelerometer shake.
